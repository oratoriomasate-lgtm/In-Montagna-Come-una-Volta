# In Montagna Come una Volta

Sito del gruppo — nessun account Claude richiesto per chi lo visita, una volta pubblicato.

## Contenuto della cartella

- `index.html` — l'intero sito (una pagina sola: testo, grafica e codice)

Le foto e i video delle gite non sono nel sito: ogni gita rimanda a un album Google Photos condiviso.

## Come pubblicarlo gratis (GitHub Pages)

Serve solo **a te** (chi pubblica) un account GitHub gratuito. Chi visita il sito dopo non ha bisogno di nulla.

1. Vai su [github.com/new](https://github.com/new) e crea un repository pubblico.
2. Nella pagina del repository, clicca **"uploading an existing file"** (o **Add file → Upload files**).
3. Trascina dentro `index.html` (questo file) e clicca **Commit changes** — se esiste già un file con lo stesso nome, GitHub lo sostituisce da solo.
4. Vai su **Settings → Pages**.
5. In **Branch** seleziona `main`, cartella `/root`, poi **Save**.
6. Dopo un paio di minuti, il link pubblico compare in cima alla stessa pagina — qualcosa come:
   `https://<tuo-username>.github.io/<nome-repository>/`

Quel link è quello da mandare nel gruppo WhatsApp.

## Come aggiornarlo con nuove gite

Torna qui in chat con Claude, mandami i dettagli della nuova gita (data, percorso, chi c'era, link all'album foto), aggiorno `index.html` e te lo ridò pronto da ricaricare su GitHub (sovrascrivendo il file esistente con "Add file → Upload files").
